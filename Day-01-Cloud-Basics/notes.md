# Day 01 - Cloud Basics ☁️

## What is Cloud Computing?

Cloud computing means using computing resources such as
servers, storage, databases and networking over the Internet
on demand.

## Why Cloud Computing?

Traditional infrastructure requires:

- Physical servers
- Hardware maintenance
- Electricity
- Cooling
- Security
- High initial cost

Cloud provides these resources on demand.

## What is AWS?

AWS stands for Amazon Web Services.

It is a cloud computing platform provided by Amazon.

AWS provides services for:

- Compute
- Storage
- Databases
- Networking
- Security
- Monitoring
- Serverless computing

## Cloud Service Models

### IaaS

Infrastructure as a Service.

Provides resources such as virtual machines, storage and networking.

Example:
Amazon EC2

### PaaS

Platform as a Service.

The cloud provider manages the infrastructure and platform,
while developers mainly focus on their application.

### SaaS

Software as a Service.

Users directly use a ready-made software application.

Examples:

- Gmail
- Google Drive
- Zoom

## Cloud Deployment Models

### Public Cloud

Cloud infrastructure is provided to multiple customers.

Example:
AWS

### Private Cloud

Cloud infrastructure dedicated to one organization.

### Hybrid Cloud

Combination of public and private cloud.

## AWS Region

A geographical area containing multiple Availability Zones.

Examples:

- Mumbai
- Singapore
- Tokyo
- London

## Availability Zone

An isolated location or group of data centers within an AWS Region.

Example:

Mumbai Region

- Availability Zone A
- Availability Zone B
- Availability Zone C

Multiple Availability Zones help improve availability and fault tolerance.

## Important Concepts

### Scalability

Ability to increase or decrease resources according to demand.

### High Availability

Keeping an application available even when some infrastructure fails.

### Pay-as-you-go

Pay according to the resources you use.
